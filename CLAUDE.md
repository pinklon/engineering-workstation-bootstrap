# Repository orientation

Read `AGENTS.md` first and follow the governing issue. It is the shared execution
policy for both coding agents. Read `CONTRIBUTING.md`, then use `make help` to find
the command service. Validate repository changes with `make validate`.

Keep authentication and user configuration separate for each coding agent.
Never activate a live workstation as a validation step. Tool readiness is not
publication clearance; see `docs/AGENT-AND-SECURITY-TOOLS.md`.
